Golf Video Game for Class

C XQuartz

Overview

The final project of my sophmore year's Fundamentals of Computing class was to create an interactive video game using C for the code and XQuartz for the graphics. The game had to include live animation, custom struct variables, and complexity.

This class was an intro into programming in C where we started with the very basics, worked our way into pointers, then studied recurrsion. The final project was our chance to show of our new skills in a fun and engaging way. Check out the results!
