Golf Video Game for Class

C XQuartz

Overview

The final project of my sophomore year's Fundamentals of Computing class was to create an interactive video game using C for the code and XQuartz's graphics.h library for the visuals. The game had to include live animation, custom structs, and complexity.

This class was an introduction to programming in C where we started with the very basics, progressed to pointers, then studied recursion. The final project was our chance to show off our new skills in a fun and engaging way. Check out the results!
